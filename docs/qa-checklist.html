ぜんぶ通しの動作確認台本

上から順に、書いてある場所を触って、書いてある挙動になるかを見るだけの台本です。 チェックはこの端末に残るので、途中で閉じても続きから再開できます。

右クリックのメニューを足しました（PC）。 ステージのダンサーを右クリックすると、向きの升（3×3）と 削除が出ます。まとめて選んだ何人かの向きを、一度に揃えられます — これまで向きを変えるつまみは1人選んでいるときしか出ませんでした。 何も無いところを右クリックすると 全員を選ぶ / 人を足す。 そのメニューに「整列」も入れました — 2人以上選んでいると 横一列に揃える / 縦一列に揃える / 左右に等間隔 / 前後に等間隔 が出ます。 揃う先は選んだ人たちの重心で、等間隔は両端を動かしません。 囲んで選ぶに「外す」も足しました — Alt（Mac は option）を押しながら囲むと、その人たちが選択から外れます。 たくさん選んでから数人だけ抜けるようになりました。 PC章の「PCでしか確かめられないこと」に22項目足しました （タブレット・スマホでは長押しで同じものが出ます。スマホ章に1項目）。

スマホを横にすると「縦向きでご覧ください」が出ます。 横だとステージで画面が埋まって道順が読めないので、 横画面には対応しないことにしました（スマホ章に2項目）。

ダンサーをぴったり重ねようとすると、置く前に確認が出ます。 重ねると上の1人しか掴めなくなるためです。 ずらして置くを選ぶとすこし横へずれて置かれ、 キャンセルなら掴む前の場所へ戻ります。

何人か選んでいるときは、どこで右クリックしても 「選んでいる人たちへのメニュー」が出ます。 丸を狙って掴み直さなくても、まとめた操作へ手が届きます。

掴んで動かすところの不具合を2つ直しました。 選んでいない人を掴んだとき、選んでいた人が一緒に動いて見えてから 元へ戻るのをやめました（動くのは掴んだ人だけです）。 シーンを切り替えた直後でも、すぐ掴めます — これまでは移動アニメが終わるまで掴めず、区間が8秒なら8秒間 反応しませんでした。

「全員を選ぶ」は Ctrl+A（Mac は ⌘+A）でも できます。選ばれるのはそのシーンに立っている人だけです （立ち位置を持たない人が混ざると、揃えても向きを変えても その人だけ動かないので）。

返してもらった3件を直しました。 「◯人を選んでいます」の帯はステージに被って邪魔だったので消しました （外すのは Esc か、何も無いところを1回叩く）。 掴んでいる間から、選んだ全員が一緒に動くようになりました （離すまで待たされません）。 縦に払ってシーンを送る操作は無くしました — 設定のつまみも、PC とタブレットでは出しません。

ブラウザの「戻る」が、Choreon の「元に戻す」になりました。 1回押すと1回ぶん戻ります。戻すものが無くなったら、次の「戻る」で 普通に前のページへ出ます（ページに閉じ込められません）。 「進む」にやり直しは割り当てていません。 PC章の末尾に4項目足しました。

スマホの台本を、まるごと書き直しました。 作るのは PC / タブレット、見るのはスマホ、と役を分けたので （README フェーズ6）、スマホは「リンクを受け取った人」の動線に しました — リンクを開く → 自分を選ぶ → 道順を読む → 動かして見る → スマホならではの所 → 作る画面を開こうとしたら。 約250項目 → 36項目。ログインも要りません （見る人はアカウントを持っていない前提です）。 先にPCで共有リンクを作って、自分のスマホへ送っておいてください。 作る操作の項目は PC 側に残っています。

「今日の分」の印を付け直しました。 前回 266項目を通しで終えてもらったので、いったん全部落として、 8/18 に変えた11項目と、8/19 に足した32項目にだけ 付けています。上の「今日の分」で絞れます。

この台本自体も変わりました。「コピーする」を押すと、 そのとき書いてあったメモは履歴へ移ります。 履歴は各項目の下に薄く残って読めますが、次の報告には入りません （同じ話を2回渡さないためです）。押し間違えたら「戻す」で戻せます。 相談したいことは、メモに 要検討 と書いてください。

確認は iPhone / Android の Safari・Chrome と PCのブラウザで行います。 本番は choreon.vercel.app、手元で見るときは npm run dev。

今回直したもの（先に見てほしい順）:

  • 狭めると、収まらない人は端へ寄るようになりました（03章）— 止めるのをやめました。元に戻す1回で、人もステージの広さも戻ります
  • 入れられない数を打っている間は、「適用」が押せなくなりました（03・04・12章）— 押してから丸めるのをやめ、その場で赤く理由が出ます
  • ステージの広さが、その場で本当に変わるようになりました（03章）— 数字だけ変わって形が変わらなかったのは不具合でした。 設定を閉じなくても、後ろのステージが広がります
  • 「舞台」の束を1つに畳みました（03章）— 作品を開いているときはその作品の広さ、ホームからはこれから作る作品の初期値。 「この作品のステージ」という別の束は無くなりました
  • 「適用」が束の下に居座るようになりました（03・04章）— 行ごとに出たり消えたりせず、いつも同じ場所にあります。 打ち替えた欄の件数が出て、まとめて効きます
  • メニューの「目盛り」も同じ3択の形になりました（03章）— 最後に残っていた1つです
  • 3択の見た目を揃えました（03・12・16章）— 拍子・動画の大きさ・テンプレートの間隔が、「ダンサー名」と同じ形に
  • 名前を変えるときの枠が、名前ぶんの幅になりました（02章）
  • ゲストのときのアカウント欄を直しました（19章）— 「ログイン / 新規登録」だけになります
  • 隊形を見てもらうと、指摘が1件ずつ返るようになりました（16章）— 頼んでいた相手が今年6月に止まっていたのを直したうえで、 指摘ごとに「直しを当てる／当てない」を選べる形にしました。 当てる先はアプリが計算します
  • 作品ぜんぶを見てもらえるようになりました（16章）— シーンを並べて流れを見てもらいます。指摘には どのシーンの話かの札が付き、押すとそのシーンが開きます
  • 右上のボタンが「メニュー」になりました（03章ほか）— 中は「ステージの見せ方 / この作品 / アプリ」の3つに分かれています。 台本の「メニュー → ◯◯」は全部このボタンです
  • 曲の頭出しを、聴いて確かめられるようになりました（12章）— 欄の下の「ここから4秒聴く」。再生位置や隊形は動きません
  • 並べ方の提案が、ステージの図で出るようになりました（16章）— 「こう並べると」の下に図が出ます。図はアプリが描いています （AIが選ぶのは隊形の名前だけ）。この並びにするで当てられて、 元に戻す1回で消えます
  • 動画のダンサーが、画面と同じ形・同じ向きになりました（16章）— これまで丸だけで、向きも180度逆でした
  • 一覧から作品の名前を変えられるようになりました（02章・15章）— これまで一覧には削除しかありませんでした
  • カウントインのあと、クリック音が続くようになりました（10章）
  • 設定の数字の欄に、入れられる範囲が出るようになりました。 ステージの広さは 4マスまで狭められます（04章）

別の端末へ引き継ぐ

チェックとメモはこの端末のブラウザにだけ残ります。 PCを操作しながらスマホで台本を読みたいときは、ここでチェックを短いコードにして、 もう片方の端末で手で打ち込んでください。 取り込むと、そのコードを作った側の端末の台本に切り替わります。

これをもう片方の端末の欄に打ち込んでください。 大文字・小文字とハイフンは気にしなくて構いません。

メモごと移したいとき（長い文字列）

気づきのメモも一緒に運びます。手では打てない長さなので、 メール・メモアプリ・チャットなど、文字を貼れる手段が要ります。
