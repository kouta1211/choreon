ぜんぶ通しの動作確認台本

上から順に、書いてある場所を触って、書いてある挙動になるかを見るだけの台本です。 チェックはこの端末に残るので、途中で閉じても続きから再開できます。

PCの報告52件すべてに手を入れました。

この台本自体も変わりました。「コピーする」を押すと、 そのとき書いてあったメモは履歴へ移ります。 履歴は各項目の下に薄く残って読めますが、次の報告には入りません （同じ話を2回渡さないためです）。押し間違えたら「戻す」で戻せます。 相談したいことは、メモに 要検討 と書いてください。

確認は iPhone / Android の Safari・Chrome と PCのブラウザで行います。 本番は choreon.vercel.app、手元で見るときは npm run dev。

今回直したもの（先に見てほしい順）:

  • 隊形を見てもらう（診断）が動くようになりました（16章）— 頼んでいた相手が今年6月に止まっていました
  • 動画のダンサーが、画面と同じ形・同じ向きになりました（16章）— これまで丸だけで、向きも180度逆でした
  • 一覧から作品の名前を変えられるようになりました（02章・15章）— これまで一覧には削除しかありませんでした
  • カウントインのあと、クリック音が続くようになりました（10章）
  • 設定の数字の欄に、入れられる範囲が出るようになりました。 ステージの広さは 4マスまで狭められます（04章）

  • 再読み込みで起動アニメが流れなくなりました（02章）— 出るのはタブを開いた最初の1回だけ

  • 紙系テーマの名前を付け直しました（14章）。文言もいくつか（01・05・16・19章）

  • 「見た目（暗い/明るい/端末）」と「このプロジェクトだけ別の見た目」を消しました（14章）

気づいたことを渡す

各項目の「メモ」に、おかしかったこと・直したいことを書いておいてください。 ここに書いたものと、チェックの付いていない項目をまとめて、 そのまま Claude Code に貼れる文章にします。

「コピーする」を押すと、そのとき書いてあったメモは履歴へ移ります。 履歴は各項目の下に薄く残って読めますが、次の報告には入りません （同じ話を2回渡さないためです）。押し間違えたら、その場の「戻す」で戻せます。

相談したいこと・案を出してほしいことは、メモに 要検討 と書いてください。 その項目は「決めずに一緒に考える」ものとして扱われます。

別の端末へ引き継ぐ

チェックとメモはこの端末のブラウザにだけ残ります。 PCを操作しながらスマホで台本を読みたいときは、ここでチェックを短いコードにして、 もう片方の端末で手で打ち込んでください。 取り込むと、そのコードを作った側の端末の台本に切り替わります。

これをもう片方の端末の欄に打ち込んでください。 大文字・小文字とハイフンは気にしなくて構いません。

メモごと移したいとき（長い文字列）

気づきのメモも一緒に運びます。手では打てない長さなので、 メール・メモアプリ・チャットなど、文字を貼れる手段が要ります。
