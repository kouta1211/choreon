# Choreon — Google AI Studio へ渡すデザイン指示書

このファイルは、**いま動いている Choreon の見た目を、Google AI Studio に
そのまま再現させる**ための資料です。値はすべて実装（`src/app/themes.css` /
`globals.css` / 各コンポーネント）から写しています。推測値はありません。

使い方は3通りあります。目的に近いものを選んでください。

| やりたいこと | 渡すもの |
|---|---|
| 新しい画面を1枚デザインさせる | §0 の貼れる指示文 ＋ §1〜§6 |
| 既存画面の改修案を出させる | §0 ＋ §1〜§7（§7 に「変えてはいけないもの」） |
| コード付きで出させる（HTML/React） | 上記に加えて §8 |

> **AI Studio 側の設定**: モデルは Gemini の最新版、Temperature は 0.4 前後
> （見た目の一貫性が要るので高くしない）。画像を添えられる場合は、実機の
> スクリーンショットを1〜2枚付けると寸法の再現度が上がります。

## 0. そのまま貼れる指示文（プロンプト本体）

以下をコピーして AI Studio の最初のメッセージに貼り、末尾の「依頼」だけを
毎回書き換えてください。§1 以降は、この指示文が参照する資料です。

```
あなたはモバイルファーストのプロダクトデザイナーです。
「Choreon」というダンスのフォーメーション（隊形）作成アプリの画面を設計します。

# アプリの中身
振付師が、ダンサーの立ち位置を曲の時間に沿って作るツールです。
上から見た長方形のステージに、ダンサーを丸いマーカーで置きます。
画面の【上がバックステージ、下が客席側】で、これは絶対に反転しません。
シーン（隊形）は「曲の何秒目か」を持ち、画面下の時間軸の上に並びます。
主に稽古場のスマートフォンで、片手で使われます。

# 守る決まり（例外なし）
1. 色は必ず下記のトークン名で指定する。16進数の直書きは禁止。
   このアプリは10種類のテーマがあり、同じ画面がテーマごとに別の色で
   描かれる。直書きは10種類すべてを壊す。
2. 警告に色を使わない。ダンサーは6色から選べ、赤いダンサーが普通に
   存在する。危険や注意は【形（アイコン）＋数値】で伝える。
3. ホバーだけで到達できる機能を作らない。ホバーはPCで足す条件であって、
   それが無いと使えない作りにしない。
4. ステージ面の上に常設のボタンを置かない。下にダンサーが来て隠れる。
5. 縦の余白がいちばん貴重。ページ自体をスクロールさせず、ステージと
   下部のドックが常に同時に見える状態を保つ。
6. 押す的は最低44px。画面の下端から24px以上あける（ホームバー対策）。
7. 角丸は --radius からの比で決める。固定値を書かない。

# 依頼
（ここに毎回の依頼を書く。例：「ダンサーを追加するボトムシートを設計して」）

出力は次の形で:
- 画面の構成（上から順に、要素と高さ）
- 各要素の指定（色トークン名・文字サイズ・余白・角丸）
- 触ったときに何が起きるか
- 判断した理由（なぜその配置にしたか）を3行以内で
```

---

## 1. 画面の骨格

### 1-1. エディタ（振付師が使う画面 / `〜767px`）

ページはスクロールしません。`h-dvh` の中を縦3ブロックに割ります。

```
ヘッダー 36〜40px … 戻る / 作品名（破線枠＋鉛筆で編集）/ 追加 / 曲 / 表示メニュー
ステージ  flex-1  … 上下中央。上=バックステージ、下=客席側
  └ ステージ直下 … 左端にテンプレート44px、中央に「客席側」ラベル
インスペクター    … ダンサー選択中だけ、ドックの直上に出る
ドック   下端固定 … 持ち手 / 操作行 / 時間軸の帯 / ミニマップ
```

- 最外側に `padding-bottom: max(24px, env(safe-area-inset-bottom))`
- ドックの合計は約187px。時間軸の帯は80px、ミニマップは14px

### 1-2. ドック（時間軸）

```
持ち手 …………… 高さ4px・幅36px の丸い棒（上スワイプでシーン一覧）
操作行 …………… 再生44px / 番号・シーン名・時刻 / 追加40px
時間軸の帯 ……… 80px。波形の上にシーンのコマを重ねる
ミニマップ ……… 14px。曲全体と、いま見ている窓
```

- **横位置がそのまま曲の時刻**です。コマとコマの間隔＝移動にかけられる時間
- 帯の中央に上下フェードの幕（`scrim` の72%）を敷き、その上にコマを置く
- 再生ヘッドは幅2px の縦線。再生中は窓の43%の位置に固定して軸が流れる
- 曲が無いときは、波形の代わりに**8カウントごとの薄い縞と拍線**を敷く

### 1-3. ビューア（ダンサーが見る画面 / `/view/[id]`）

**編集の操作を一切持ちません。** 階層がエディタと逆で、主役はスクラブです。

```
ヘッダー 40px … 作品名 / 自分のポジションのピル（押すと選び直し）
ステージ  flex-1
道順の1行 …… ステージ直下。「下手前へ 約4歩（1.6秒かけて）」＋「ぜんぶ」
曲の1行  32px … 「同じ曲をこの端末で選ぶ」
スクラブ帯 56px … 画面幅いっぱい。再生ヘッドは常に中央（50%）
目盛り   14px
```

- 自分＝直径36pxの塗り＋6pxのリング＋名前、他人＝直径26pxの**輪郭だけ**
  （塗りのまま薄くすると「薄い誰か」が並んで結局読めない。塗り→輪郭が要点）
- 再生ボタンは36pxの枠線ボタンに**格下げ**する（主役はスクラブ）
- 横持ち・768px以上ではステージの右に道順を置く2カラム

## 3. 角丸・寸法・タイポ

### 角丸は `--radius` からの比

既定は `--radius: 12px`。テーマによって 0 / 4 / 8 / 12 / 14 と変わり、
画面じゅうの角が一斉に付いてきます。**固定値を書かせないこと。**

| 名前 | 係数 | 既定での値 |
|---|---|---|
| `rounded-sm` | ×0.3333 | 4px |
| `rounded-md` | ×0.5 | 6px |
| `rounded-lg` | ×0.6667 | 8px |
| `rounded-xl` | ×1 | 12px |
| `rounded-2xl` | ×1.3333 | 16px |
| `rounded-3xl` | ×2 | 24px |

`rounded-full`（円）は再生ボタン・ドット・ダンサーのマーカーだけ。

### 決まっている寸法

| もの | 値 |
|---|---|
| ダンサーのマーカー | 40px（頭20px＋鼻先8px）。ビューアの自分は36px、他人26px |
| 回転ハンドル | 中心から46px・見た目24px・**判定44px** |
| 曲線の制御点 | 見た目14px・判定44px・4px未満の移動では確定しない |
| 再生ボタン | 48px（スマホでも下げない）。ビューアだけ36px |
| アイコンの的 | 44px（見た目は40px。周囲2pxは透明にして隣に触れさせない） |
| 色チップ | 22px |
| 時間軸のコマ | スマホ46×34（選択中56×42）/ タブレット58×43 / PC 72×54 |
| ドックのサムネイル | 74px（一覧シートは78px） |

### タイポ

フォントは **Geist Sans**。数値・秒数・シーン番号・件数は **Geist Mono**。
（機能的な差を「数値だけ」に与えるための使い分けです）

| 用途 | 指定 |
|---|---|
| ブランド（認証画面） | 34px / 700 / -0.03em |
| ブランド（ヘッダー） | 19px / 600 / -0.02em |
| 作品名 | 15px / 600 |
| シーン名（ドック） | 14px / 600 |
| 本文・入力 | 14px / 400 |
| ラベル・補助 | 12px / 500 |
| 極小（ステージの上下ラベル） | 10px / 600 / letter-spacing .16em |
| ダンサー名 | 10px / 700 ＋ `text-shadow: 0 1px 2px rgba(0,0,0,.85)` |
| 数値（Mono） | 9.5〜11px |

## 4. 部品の作り（そのまま真似させる）

### 4-1. 押し心地（全ボタン共通）

**凸 → 凹**。`:active` は使わず、ポインタのイベントで自分で持ちます
（iOS Safari で発火しない場面があり、指を外へ滑らせたときに解除されない）。

| 種類 | 押したとき |
|---|---|
| 主ボタン | 明度 −6% ＋ 内側に影 ＋ `scale(.965)` |
| 副ボタン（枠線） | 面を地より暗く ＋ 枠線を一段明るく ＋ `scale(.965)` |
| アイコンの的 | 同上 ＋ `scale(.92)`（小さいものほど深く沈める） |
| 丸ボタン（再生） | `scale(.94)` |
| **掴んで動かすもの** | 沈めず `scale(1.08)` へ**持ち上げる**＋影を伸ばす |

- 押す瞬間は速く（.11s）、離してからは遅く（.2s）戻す
- 指を押したまま外へ滑らせたら押下を解除し、**発火もしない**
- 波紋（ripple）は入れない。Androidの語彙で、ステージの丸と混ざる
- `prefers-reduced-motion` では大きさを変えず、面の明暗だけで示す

### 4-2. 重なる板（モーダル・シート・ポップオーバー）

素材は**テーマが決めます**。暗い系は磨りガラス、紙系はトレーシングペーパー、
黒板は曇ったアクリル。板は次の5つのトークンで描きます。

```
--overlay-bg      rgba(31,31,35,.84)      面
--overlay-blur    blur(20px) saturate(1.4) ぼかし
--overlay-line    rgba(255,255,255,.11)    縁
--overlay-sheen   inset 0 1px 0 rgba(255,255,255,.13)  上端の照り
--overlay-shadow  0 18px 50px -16px rgba(9,9,11,.92)   影
```

- 幕のぼかしは板ではなく**下のコンテンツ側**に掛ける（板に掛けると板がぼける）
- `backdrop-filter` は重なる板にだけ。ヘッダーやドックに常設すると、
  ステージのドラッグ中ずっと再合成が走って重くなる

### 4-3. 確認ダイアログ

**「一緒に何が消えるか」を数で書く**のが要点です。

1. アイコン38px（破壊的操作は赤系）＋ 見出し15px/600 ＋ 本文12px
2. チップの行 — `6 配置` `1 導線` `00:12.40` のような枠線チップ（26px高）
3. 注記 — 「**削除は元に戻せません。**（移動や向きの変更は「元に戻す」で
   戻せます）」。履歴との違いを必ず書く
4. ボタン2つ（各46px高・横並び）。左がキャンセル、右が破壊（赤）

位置は `〜767px` で**下寄せ**（ボタンが親指の届く高さに来る）。
768px以上は中央・最大420px。

### 4-4. トースト

- 置き場所は画面下端ではなく**ドックの直上**（下端は指とホームバーで埋まる）
- アイコン20pxの中だけ色を持ち、**面の色は変えない**（ダンサーの色と競合させない）
- 滞在4秒、「元に戻す」付きは7秒。**横スワイプで即消し。×は置かない**
- 同時に出るのは1つだけ。積み上げない

### 4-5. 説明ポップオーバー

`title` 属性は使いません（出るまで遅く、テーマも当たらず、タッチでは出ない）。
出し方は3つだけ: **長押し450ms** / 行の右端の `?` 24px / その機能を初めて
ONにしたときの1回。PCでは**ホバー400msを足すだけ**で、別部品を作りません。

## 5. ステージの描き方（いちばん間違えやすい所）

- **上＝バックステージ、下＝客席側。** 反転させない
- 1マス＝実寸90cm。既定は横14×縦10マス（12.6m×9m）
- 幅を偶数にしているのは、奇数だと中心が格子の間に来て「ちょうど中央」に
  置けなくなるため
- 「上手（かみて）／下手（しもて）」は**客席から見た向き**。画面左＝下手
- 警告の定位置: **左上＝顔被り / 右上＝移動が速すぎる / 右下＝移動中の衝突**
- バミリ（床の目盛り）は客席側の辺に置き、角までは伸ばさない

## 6. 10のテーマ（同じ画面が10通りに描かれる）

| id | 名前 | 系統 |
|---|---|---|
| `midnight` | ミッドナイト・ピンク（既定） | 暗い |
| `neon` | ネオン・シアン（発光・ガラス） | 暗い |
| `amber` | アンバー・ステージ（舞台照明・板張り） | 暗い |
| `mono` | モノクローム（UIは無彩色だけ） | 暗い |
| `chalk` | 黒板＋チョーク | 暗い（素材だけ違う） |
| `paper` | 紙の隊形図（クリーム紙・赤鉛筆） | 紙・素材 |
| `gridnote` | 方眼ノート＋青インク | 紙・素材 |
| `kraft` | クラフト紙＋活版 | 紙・素材 |
| `tracing` | トレーシングペーパー | 紙・素材 |
| `whiteboard` | ホワイトボード＋マーカー | 紙・素材 |

背景の質感は別軸で6種（フラット／ネビュラ／ホリゾント幕／スポットの円光／
方眼と目盛り／グレイン／暗幕）。**装飾は白3.5%・色20%以下、ステージの外だけ。**

紙・黒板系では次が自動で切り替わります。デザイン案もこの前提で描かせてください。

- ダンサーのマーカーが**塗り → 輪郭＋頭文字**になる
- ダンサー名のラベルが**黒文字＋白影**になる
- 影が弱くなり、角丸が 0〜4px になる

## 7. 変えてはいけないもの（改修案を出させるとき必ず添える）

1. ステージの座標系とアスペクト比（上=奥 / 下=客席）
2. ダンサーの6色と、その順番
3. 警告に色を使わないこと
4. タップ領域44px、下端24px、`h-dvh`（ページをスクロールさせない）
5. 日本語のドメイン用語 — バックステージ／客席側／上手・下手／
   シンメトリーモード／顔被りチェック／マイ・フォーカス／バミリ／
   8カウント（「小節」ではない）
6. 「シーンは曲の何秒目か」を持つこと。相対的な「何秒かけて」ではない

## 8. コードで出させるときの追加指示

```
実装は次の構成に合わせてください。

  shadcn 既定のクラスは使わず、必ず下記のトークン名に置き換える:
    bg-page / bg-surface / bg-surface-raised / bg-surface-strong /
```
