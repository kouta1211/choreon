## 0. この仕様が禁止するもの（最初に読む）

「AIが作ったような画面」に共通する特徴を、名指しで禁止します。レビューはこの節を
チェックリストとして使ってください。**1つでも該当したら差し戻し。**

| # | 禁止 | 例外 |
|---|---|---|
| 1 | **グラデーション** | 波形の上に敷く中央の幕（情報を読ませるための機能的なもの）と、認証画面の背景光の2つだけ |
| 2 | **装飾のための枠線** | 「押せる物」の輪郭と、面と面の境界の 1px ヘアラインのみ |
| 3 | **影の多用** | 影は2種類しか存在しない（§6-3）。カードやボタンに影を付けない |
| 4 | **不揃いな余白** | 4 の倍数以外の余白を書かない（§4） |
| 5 | **角丸の混在** | 3段階しかない（§5）。`rounded-[13px]` のような一点物を作らない |
| 6 | **2色目のアクセント** | アクセントは1色。意味を運ぶ色はダンサーの6色だけ（§2-4） |
| 7 | **アイコンとラベルの重複** | 「🗑 削除」のように同じことを2回言わない。どちらか一方 |
| 8 | **面を持つ要素の入れ子3段以上** | カードの中のカードの中のカード、を作らない |
| 9 | **中央揃えの多用** | 読ませる文字は左揃え。中央揃えは空状態とダイアログの見出しだけ |
| 10 | **絵文字をUIに使う** | 一切使わない。アイコンは lucide-react のみ |

## 1. 5つの原則

1. **色は意味を運ぶときだけ使う。** 地・面・文字はすべて無彩色。色が付いているものは
   「いま選んでいる」「いま鳴っている」「誰であるか」のいずれかを表している
2. **階層は透明度で作る。** 枠線でも影でもなく、黒の上に重ねる白のアルファで奥行きを出す
3. **触れるものは、触れると分かる形をしている。** 44px の的、押し込み、持ち上げ
4. **ステージは聖域。** ダンサーの動き以外のものを置かない
5. **余白は秩序。** 4/8 の格子から外れた数字を1つも書かない

## 2. カラー

### 2-1. 地と面（黒 ＋ 白のアルファ）

**ベースは純黒 `#000000`。** その上に白を重ねて階層を作ります。面ごとに色を持たせません
（`zinc-800` `zinc-900` のような別々の値をやめる、という意味です）。

| トークン | 値 | 使う場所 |
|---|---|---|
| `--bg` | `#000000` | ページの地 |
| `--surface-1` | `rgba(255,255,255,0.04)` | ドック、ヘッダー、カード |
| `--surface-2` | `rgba(255,255,255,0.07)` | その上に乗る面（入力欄、チップ、副ボタン） |
| `--surface-3` | `rgba(255,255,255,0.11)` | さらに上（押下中、ホバー、選択中の行） |
| `--stage` | `#0A0A0B` | ステージの内側。**ここだけ不透明**（下に何も透けてはいけない） |
| `--stage-grid` | `rgba(255,255,255,0.06)` | ステージの格子 |
| `--hairline` | `rgba(255,255,255,0.10)` | 面と面の境界。1px |
| `--hairline-strong` | `rgba(255,255,255,0.18)` | 押せる物の輪郭。1px |
| `--scrim` | `rgba(0,0,0,0.64)` | シート・モーダルの下に敷く幕 |

**ステージだけ不透明にする理由**: 隊形の点は最大10個が近接して並びます。地が透けて
コントラストが揺れると、点が背景に沈む位置が生まれます。

### 2-2. 文字

| トークン | 値 | 用途 | 下限 |
|---|---|---|---|
| `--text-primary` | `#FFFFFF` | 見出し、いま選んでいるものの名前 | — |
| `--text-secondary` | `rgba(255,255,255,0.64)` | 本文、ラベル | — |
| `--text-tertiary` | `rgba(255,255,255,0.46)` | 補助、単位、メタ情報 | **11px 未満で使わない** |
| `--text-disabled` | `rgba(255,255,255,0.26)` | 無効 | 文字を読ませない前提 |

`0.46` が下限です。これより暗い文字を情報に使わないでください（暗い稽古場のスマホで消えます）。

### 2-3. アクセント（1色だけ）

| トークン | 値 | 用途 |
|---|---|---|
| `--accent` | `#EC4899` | 再生ボタン、主ボタン、選択中の縁、波形の再生済み部分 |
| `--accent-hover` | `#F472B6` | ホバー／押下の明るい側 |
| `--accent-text` | `#F9A8D4` | **暗い地の上に置くアクセント色の文字**（`--accent` そのままは小さい文字で読みにくい） |
| `--accent-on` | `#FFFFFF` | アクセントを敷いた面の上の文字 |

**規則**:
- アクセントを敷いた面に **13px 未満の文字を載せない**（コントラストが足りません）
- アクセントは **1画面に最大3か所**。それ以上あるとどれが「いま」なのか分からなくなります
- アクセントで**塗る**のは、再生ボタン・主ボタン・波形の再生済み・選択中のコマの縁だけ

### 2-4. ダンサーの6色（UIの色ではなく、データの色）

```
#3B82F6  #EF4444  #10B981  #F59E0B  #8B5CF6  #EC4899
```

**この6色は変更できません。** Supabase に保存されている実データで、色チップの選択状態の
照合にも使っています。UIのパレットとは別の層として扱ってください。

> ⚠ **「ダンサーのコマにアクセントカラーを使う」という指示は採用できません。**
> 6色は「誰であるか」を運ぶ唯一の手段で、単色にすると**このアプリの中心機能が壊れます**。
> ただし指示の意図（＝画面から無駄な色を消す）は、**UI側を完全に無彩色にする**ことで
> 満たします。結果として、画面に出る色は「アクセント1色」と「ダンサーの6色」だけになり、
> **色が付いている＝意味がある**という規則がむしろ強くなります。

純黒の上では 6色のうち青（`#3B82F6`）と紫（`#8B5CF6`）が沈みます。**描画時に明度を
+8% 補正**してください（保存値は変えない）。

### 2-5. 警告に色を使わない

ダンサーが赤を選べる以上、赤は警告になりません。**形（アイコン）＋数値**で伝えます。

| 警告 | 形 | 定位置 |
|---|---|---|
| 顔被り | 目に斜線 | ステージ**左上** |
| 移動が速すぎる | 三角に感嘆符 | ステージ**右上** |
| 移動中の衝突 | 2つの丸が重なった印 | ステージ**右下** |

バッジは `--surface-3` の面に `--text-primary` のアイコン 16px ＋ 数値（Mono 11px）。
**色を持ちません。**

## 3. タイポグラフィ

**Geist Sans**（本文）と **Geist Mono**（数値）。数値・秒数・シーン番号・カウントは
必ず Mono にします。「機能的な差を数値だけに与える」ためです。

| 役割 | サイズ / 行間 | ウェイト | 字送り | 色 |
|---|---|---|---|---|
| Display（認証のブランド） | 32 / 1.1 | 700 | -0.03em | primary |
| Title（画面の見出し、作品名） | 20 / 1.3 | 600 | -0.02em | primary |
| Heading（シート・ダイアログの見出し） | 17 / 1.35 | 600 | -0.01em | primary |
| Body（本文、入力） | 15 / 1.5 | 400 | 0 | secondary |
| Label（ボタン、行の名前） | 13 / 1.4 | 500 | 0 | secondary |
| Caption（補助、説明） | 11 / 1.45 | 500 | 0 | tertiary |
| Mono S（時刻、番号、カウント） | 11 / 1 | 500 | 0 | tertiary |
| Mono M（再生位置） | 13 / 1 | 500 | 0 | primary |

**階層はウェイトと色で作ります。** サイズを7段より増やさないでください。
「少し大きくする」で階層を作ると、画面ごとに基準がずれます。

- ダンサー名（ステージ上）: 10 / 700 ＋ `text-shadow: 0 1px 2px rgba(0,0,0,.85)`
- **全角と半角を混ぜた行では `font-feature-settings: "palt"` を使わない**（数値がずれます）

## 4. 空間（4/8 グリッド）

**4 の倍数以外を書かない。** 迷ったら 8。

```
4  8  12  16  24  32  48  64
```

| 用途 | 値 |
|---|---|
| 画面の左右 | 16 |
| セクションの間 | 24 |
| 関連する要素の間 | 8 |
| 行の中の要素の間 | 8 または 12 |
| カード・シートの内側 | 16 |
| ダイアログの内側 | 24 |

### 4-1. 高さの段（これ以外を作らない）

| 高さ | 用途 |
|---|---|
| 28 | チップ、小さいバッジ |
| 32 | セグメントのセル、密なリストの行 |
| 40 | 副ボタン、アイコンの的（狭い画面のヘッダー） |
| 44 | **タップの最小**。リストの行、標準のボタン |
| 48 | 主ボタン、再生ボタン |
| 56 | シートの主ボタン、ビューアのスクラブ帯 |

**44px はグリッドの値ではなく、触れる下限です。** 40 の的を使うのは、周囲8px以上の
余白で実質44px以上を確保できる場所だけ。

### 4-2. いまの実装からの写像（実装者向け）

現在の値は仕様書由来の一点物が多く、格子から外れています。次のように寄せてください。

| 現在 | → | 現在 | → |
|---|---|---|---|
| 46px（ボタン高） | 48 | 13px（余白） | 12 |
| 38px（履歴ボタン） | 40 | 11px（余白） | 12 |
| 34px（インライン入力） | 32 | 9px（余白） | 8 |
| 26px（チップ） | 28 | 18px（余白） | 16 |
| 30px（小ボタン） | 32 | 14px（余白） | 16 |

## 5. 角丸（3段階＋円）

すべて `--radius`（既定 12px）からの比で書きます。テーマが `--radius` を変えると
画面じゅうの角が一斉に付いてくる仕組みを維持するためです。

| 段 | 値 | 使う物 |
|---|---|---|
| **円（full）** | `9999px` | 再生ボタン、ダンサーのマーカー、色ドット、ピル、トグル |
| **control** | `--radius * 0.83` ＝ 10px | ボタン、入力欄、チップ、セグメント |
| **panel** | `--radius * 1.33` ＝ 16px | カード、パネル、トースト、ポップオーバー、ステージ |
| **sheet** | `--radius * 2` ＝ 24px | シートの上端、モーダル |

**一点物を作らない。** 上の4つ以外の角丸を書いた時点で差し戻しです。

## 6. 質感

### 6-1. すりガラス（使う場所を限定する）

```
背景     rgba(18,18,20,0.72)
ぼかし   blur(24px) saturate(1.3)
縁       1px  rgba(255,255,255,0.12)（上端だけ 0.16 にして「板の縁」を出す）
```

**使ってよい場所**（一時的に重なるものだけ）:
シート／モーダル／ポップオーバー／トースト／ドロップダウンメニュー／ビューアの道順バー

**使ってはいけない場所**（常設のもの）:
**ドック（タイムライン）／ヘッダー／ステージ**

> ⚠ **「タイムラインパネルにすりガラスを使う」という指示は採用できません。**
> ドックは常に画面にあり、その上でステージのドラッグが毎フレーム走ります。常設面に
> `backdrop-filter` を掛けると、ドラッグ中ずっと背後の再合成が起き、**指の追従が目に見えて
> 落ちます**（このアプリで最も避けたい劣化です）。
> 代わりに **`--surface-1` の面 ＋ 上端 1px のヘアライン**で「浮いている板」を作ります。
> 透明度で階層を作るという指示の芯は、こちらでも満たせます。

`@supports not (backdrop-filter: blur(1px))` のときは背景の不透明度を `0.94` に上げる。
`prefers-reduced-transparency` のときはぼかしを切って不透明にする。

### 6-2. 面の重ね方

枠線で囲うのではなく、**アルファを1段上げる**ことで手前に出します。

```
地(#000) → surface-1 のドック → surface-2 の入力欄 → surface-3 の押下中
```

面の入れ子は**2段まで**。3段目が要るなら、それはシートかモーダルにすべき内容です。

### 6-3. 影（2種類だけ）

| トークン | 値 | 使う物 |
|---|---|---|
| `--shadow-modal` | `0 24px 64px -24px rgba(0,0,0,0.80)` | モーダル、シート |
| `--shadow-lift` | `0 8px 24px -8px rgba(0,0,0,0.60)` | 掴んで持ち上げている物（ダンサー、コマ） |

**それ以外に影を使わない。** ボタン・カード・パネルは影を持ちません。

## 7. モーション（手触り）

| 場面 | 指定 |
|---|---|
| 押し込み | `110ms cubic-bezier(.2,.7,.2,1)`、離すと `200ms`（戻りを遅く） |
| 主ボタン・副ボタン | `scale(.97)` ＋ 面を1段暗く |
| アイコンの的 | `scale(.92)`（小さい物ほど深く沈める） |
| **掴んで動かす物** | 沈めず `scale(1.06)` ＋ `--shadow-lift` |
| シートの登場 | `340ms cubic-bezier(.2,.9,.25,1)`、退場 `200ms ease-in` |
| モーダル | 幕 `180ms` フェード、板は `translateY(8px) scale(.98)` から `260ms` |
| シーンの切り替え | 位置の補間は ease-out。曲の再生中は曲の時刻が正 |

- **波紋（ripple）を使わない**。ステージのダンサーの丸と混ざります
- `prefers-reduced-motion` では大きさを変えず、面の明暗だけで状態を示す
- **点滅させない**。再生中は外側に淡いリング（`0 0 0 6px accent/.16`）で示す

## 8. コンポーネント

### 8-1. ボタン

| 種類 | 形 | 通常 | 押下 |
|---|---|---|---|
| 主（primary） | control / h48 | `--accent` ＋ 白文字 15/600 | `brightness(.94)` ＋ `scale(.97)` |
| 副（secondary） | control / h44 | `--surface-2` ＋ secondary文字 13/500 | `--surface-3` ＋ `scale(.97)` |
| 静か（quiet） | control / h44 | 面なし ＋ secondary文字 | `--surface-2` |
| アイコン | control / 44×44（見た目40） | 面なし ＋ secondary | `--surface-2` ＋ `scale(.92)` |
| 再生 | 円 / 48 | `--accent` ＋ 白 | `scale(.94)` |
| 破壊 | control / h48 | `--surface-2` ＋ **文字だけ** `#FF6B6B` | `--surface-3` |

**破壊的な操作を赤で塗らない。** 面を赤くすると、隣にいる赤いダンサーと同じ強さになります。

### 8-2. シート（下から出る板）

- 上端 sheet 角丸、掴み手 36×4（`--hairline-strong`）
- 見出し 17/600 ＋ 右に補助（Mono 11 / tertiary）
- 内側 16、要素の間 24
- **指で追従して引き下げられる**。高さの40%または速度0.5px/msで閉じる。幕も連動して薄くなる
- 広い画面（1200px〜）ではシートにせず、常設パネルか中央モーダル（`max-w-[560px]`）

### 8-3. ダイアログ（確認）

- 幕 `--scrim` ＋ 背後を `blur(2px)`
- 板 24 の内側、要素の間 16
- 構成: アイコン40（`--surface-2` の円）→ 見出し17/600 → 本文15/400 secondary →
  **一緒に消える物のチップ**（Mono 11 / h28 / control）→ 注記 → ボタン2つ（h48・横並び）
- 狭い画面では**下寄せ**（親指の届く高さ）、768px以上は中央

### 8-4. トースト

- ドックの直上、左右16、glass、panel 角丸、h56
- アイコン20（円・`--surface-3`）＋ 本文13/500 ＋ 右にボタン1つ（h32）
- **同時に1つだけ**。4秒（元に戻す付きは7秒）。横スワイプで消える。×は置かない

### 8-5. 入力

- 高さ44、`--surface-2`、control 角丸、枠線なし
- フォーカス時のみ `--accent` の 1px ＋ `ring 3px accent/16`
- 数値は上下矢印を消し、既定はチップ表示。タップするとその場が入力欄になる

### 8-6. セグメント / スライダー / トグル

- **セグメント**: 3択まで。h32、control 角丸、`--surface-2`。選択中のセルだけ
  `--surface-3` ＋ primary文字（**アクセントで塗らない**。3つのうち1つが常に光るのは騒がしい）
- **スライダー**: トラック h4（`--surface-3`）、通過部 `--accent`、つまみ 18 の円（`--bg` で2px縁取り）。掴むと `scale(1.15)`
- **トグル**: 44×26 のピル。オフ `--surface-3`、オン `--accent`。つまみは白22の円

### 8-7. カード（作品の一覧）

- `--surface-1`、panel 角丸、内側16、行の間8、**枠線なし・影なし**
- 左にサムネイル（stage 面・panel 角丸・幅80）
- 右上に作品名 Title、その下に Mono 11 の `5 シーン · 6 人 · 7:24`
- ダンサーの色ドット 6（円）を横並び
- 削除は行の右端に44のアイコン的（`stopPropagation`）

## 9. エリアごとの方針

### 9-1. ステージ（聖域）

**置いてよい物はこれだけ**:
ダンサーのマーカー／その名前／回転ハンドル（選択中のみ）／曲線の制御点（選択中のみ）／
導線／格子／バミリ／中心線／上下のラベル／警告バッジ（三隅の定位置）

**置いてはいけない物**: ボタン、メニュー、トースト、説明。
**いまステージ内右下にある「元に戻す／やり直す」はステージの外へ出してください。**
下にダンサーが来ると隠れ、聖域の原則にも反しています（移設先はドックの操作行を推奨）。

- ステージの面 `--stage`、panel 角丸、**枠線は下辺（客席側）だけ** 1px `--hairline-strong`
- 格子は `--stage-grid`。1マス＝90cm という情報を持つので消さない
- マーカー: 直径40（円）＋ 中心から鼻先8で向きを示す。選択中は外側に 6px のリング
- 上下のラベル「バックステージ」「客席側」は Caption / tertiary / 字送り `.16em`

### 9-2. タイムライン（重厚に、精密に）

このアプリで最も長く見られる場所です。**ここだけは密度を上げてよい。**

```
帯 h80（1200px〜は h96）  --surface-1 の面、上端に1px --hairline
  波形（未再生）  rgba(255,255,255,0.28)
  波形（再生済み） --accent
  中央の幕        上下フェード（唯一許可されたグラデーション）
  シーンのコマ    --stage の面、1px --hairline、選択中は --accent 2px
  再生ヘッド      2px #FFFFFF ＋ 外側に 0 0 8px rgba(255,255,255,.35)
目盛り h16       Mono 11 / tertiary、絶対配置
```

- **コマの縮退**（コマ → 番号の旗 → 「4シーン」の束ね）はこのアプリ独自の見どころ。
  `180ms` のクロスフェードで、大きさは飛ばさず補間する
- 曲が無いときは波形の代わりに **8カウントの縞**（`rgba(255,255,255,0.03)` の交互）と
  拍線（1px）。**「機能が欠けた画面」に見せない**
- 再生中は再生ヘッドを窓の43%に固定して軸を流す

### 9-3. ドック（下端）

- `--surface-1` ＋ 上端1px、上端だけ sheet 角丸。**すりガラスにしない**（§6-1）
- 段は **3段まで**（掴み手／操作行／時間軸）。ミニマップは 1200px 以上でのみ出す
- 操作行: 再生48（円・アクセント）／シーン番号 Mono ＋ 名前 Label ／ 再生位置 Mono M ／
  追加44。**ここに元に戻す・やり直すを移す**

### 9-4. ヘッダー

**アイコンを5つ以上並べない。** いまは6つあり、初見で判別できません。

```
←戻る │ 作品名（Title・破線枠＋鉛筆で編集可） │ ＋人 │ ≡
```

曲・共有・診断・動画は `≡` の中に**見出し付きで**まとめる（「この作品」「渡す」「表示」）。

### 9-5. ビューア（ダンサー向け）

同じ部品を使い、寸法だけ上げます。滞在時間が短く、片手で、動きながら見る画面です。

- スクラブ帯 h56（画面幅いっぱい）、再生ヘッドは**中央固定**
- 自分＝直径36の塗り＋リング＋名前／他人＝直径26の**輪郭だけ**（塗りを薄くしない）
- 道順の1行は glass の板（panel 角丸・h56）に「→ 下手前へ 約4歩（1.6秒かけて）」
- 再生ボタンは 40 の quiet ボタンに**格下げ**する（主役はスクラブ）

## 10. テーマの扱い（判断が要る点）

いまは10テーマ＋質感7種があります。この仕様は **「ダーク1本を本気で作る」** 方針なので、
次のどれかを選んでください。

| 案 | 内容 | 向き |
|---|---|---|
| **A（推奨）** | ダーク（この仕様）を既定にし、**「紙の隊形図」1本だけ**を残す。他8種は削除 | 選択肢が減り、両方を本気で作れる。紙は現場移行の物語になる |
| B | 10種を残し、ダークだけをこの仕様で作り直す | 作業は小さいが、既定以外は今後も検証されないまま |
| C | テーマ機構ごと廃止 | いちばん静かだが、`--radius` の仕組みも失う |

**推奨はA。** 「選べること」自体は価値になっておらず、10種あることで**どれも中途半端**に
なっています。

## 11. 実装への影響（見積もりのため）

| 変更 | 影響範囲 |
|---|---|
| 地と面を「黒＋アルファ」へ | `themes.css` のトークン定義。既存のクラス名（`bg-surface` 等）は変えずに値だけ差し替えられる |

| 影を2種に絞る | 数か所 |
| ヘッダーの整理・履歴の移設 | 構造の変更。**この仕様で唯一、配置が変わる部分** |
