# Choreon UI仕様書

このドキュメントは Choreon の現在のUIの参照資料です。
実装の詳細（状態管理・フック・データ取得の仕組み）は含めず、
「画面上に何があり、それが何を扱い、何が起きるか」だけを記述しています。

> **経緯**: 初版はリデザインを Claude Design に依頼するためのハンドオフとして書かれ、
> その確定案（Turn 5）を実装したのが現在の姿です。デザイン確定案からの意図的な逸脱は
> [7章](#7-デザイン確定案からの逸脱) にまとめてあります。

---

## 1. アプリの目的

**Choreon は、ダンスのフォーメーション（隊形）を作るためのスマートフォン向けアプリです。**

振付師やチームのリーダーが、曲の進行に合わせて「誰がステージのどこに立ち、次にどこへ、どのくらいの時間をかけて移動するか」を組み立て、再生して動きを確認できます。紙やホワイトボードで隊形図を描く作業を置き換えるものです。

| 概念 | 意味 |
| --- | --- |
| **プロジェクト** | 1曲・1演目にあたる作業単位。ステージの広さ（マス数）を持つ |
| **シーン** | ある瞬間の隊形1コマ。順番を持ち、「このシーンへ移動してくるのにかかる秒数」を持つ |
| **ダンサー** | 演者1人。名前と色を持ち、各シーンごとに「位置(x, y)」「向き(角度)」を持つ |

つまりアプリは **「シーンの並び ＝ 隊形の絵コンテ」** であり、シーンを順に再生すると、ダンサーが次の位置へ滑らかに移動していくアニメーションになります。

### 想定利用シーン

- **端末はスマートフォンが主**。練習場・スタジオで片手に持って使う
- 立ったまま、明るい／暗い両方の環境で使う（ダークテーマ固定なのはこのため）
- 操作は**指でのドラッグが中心**
- **時間軸（タイムライン）と空間（ステージ）を1画面で同時に見たい** ← レイアウトの最大の制約

## 3. エディタ画面

### 3-1. 骨格

**`h-dvh` の縦3ブロック。ページ自体はスクロールしません。**

```
┌─────────────────────────────────────┐
│ A ヘッダー（高さ固定）                 │ ← 戻る / プロジェクト名 / 人追加 / 表示とモード
├─────────────────────────────────────┤
│                                     │
│ B ステージ（flex-1 = 残り全部）        │ ← 「バックステージ」ラベル
│    ┌───────────────────────────┐   │   ステージ本体
│    │ グリッド / 中心線 / 導線      │   │   「客席側」ラベル
│    │ ダンサー          [↶][↷]  │   │   ※履歴は内側の右下に浮く
│    └───────────────────────────┘   │
│                                     │
├─────────────────────────────────────┤
│ C インスペクター（選択時のみ・浮く）     │ ← ドックの直上。高さを取らない
│ D ドック（高さ固定・下端に貼り付く）      │
└─────────────────────────────────────┘
```

**ステージのサイズ決定**は `width: min(100cqw, 100cqh × W / H)` ＋ `aspect-ratio`。
「枠内に収まる最大サイズを、縦横比を保って」という規則です。`max-width`/`max-height` では表現できません（確定している軸が勝ち、もう片方だけが詰められて比率が壊れる）。比率が壊れるとダンサーの％座標が全部ずれます。

### 3-2. A. ヘッダー

| 要素 | 内容 |
| --- | --- |
| 戻る | ChevronLeft。プロジェクト一覧へ |
| プロジェクト名 | **破線枠＋鉛筆**。タップでその場編集（Enter/blur確定、Escape取消） |
| ダンサーを追加 | UserPlus。ボトムシートを開く |
| **表示とモード** | SlidersHorizontal。**オンの数をバッジ表示**。押すとメニューが開く |

**表示とモードのメニュー**（4行、各行にアイコン＋名前＋1行説明＋トグル）

| モード | 説明文 | 初期値 |
| --- | --- | --- |
| シンメトリーモード | 動かすと左右の相手も連動する | オフ |
| グリッドを表示 | 1マス=約90cm | **オン** |
| 導線を表示 | 次のシーンへの動きを線で描く | オフ |
| 顔被りチェック | 手前の人に隠れる人を赤くする | オフ |

右上に「3人 · 2シーン」。背景タップ／Escape で閉じます。

### 3-3. B. ステージ

上が**バックステージ（舞台奥）**、下が**客席側**。上下に小さなラベル。

- **枠**: ピンク2px、角丸12px、内側 `#141417`
- **グリッド**: `#2c2c32`、1マス＝1ユニット＝実寸約90cm
- **中心線**: シンメトリーON時、中央に薄いピンクの縦線
- **スナップ線**: ドラッグ中に格子へ吸着している間だけ発光したピンク線（縦横両方＝交差点）
- **暗幕**: マイ・フォーカス中、全体がわずかに暗くなる
- **履歴ボタン**: 内側の**右下**に38px×2。無効時は `opacity-30`（形は残す）

#### ダンサーマーカー

真上から見た人物（円の頭＋鼻先の三角）。円の下に名前が常に正立。

| 状態 | 見た目 |
| --- | --- |
| 選択中 | ピンクの実線リング |
| キーボードフォーカス | ピンクの破線リング |
| マイ・フォーカス | 琥珀色の太いリング＋1.15倍／他は30%に減光 |
| 顔被り | 本体が警告赤に |
| 移動距離超過 | 右上に琥珀色の△バッジ（常時判定） |

**操作**: ドラッグで移動（8px閾値、離すと格子に吸着）／タップで選択／矢印キーで微調整（Shiftで大きく）／選択中に出る回転ハンドル（本体から46px、視覚24px、**タップ44px**）

#### 導線

選択中シーン → 次のシーンへの軌跡を、ダンサーの色の**矢印付き点線**で描画。

- **制御点ハンドル**: 選択中のダンサーの線にだけ表示。視覚14pxの正円（色＋白フチ）、**タップ44px**。4px未満の移動では確定しない。ダブルクリックで直線に戻る
- ここで描いた曲線どおりに、実際の移動も行われます
- **シーンを移動している最中**は、通っている区間の線が増減します（進む＝食べながら／戻る＝吐き出しながら）

#### 空状態（シーン0件）

破線枠のステージに「まだシーンがありません」＋**「最初のシーンを作る」**ボタン。

### 3-4. C. インスペクター（ダンサー選択時）

**ドックの直上に浮きます（absolute）。出入りしてもステージは1pxも動きません。**

- 左端に4pxの**ダンサー色の帯**、面に同じ色のグラデーション
- **1段目**: 名前（破線枠＋鉛筆）／個別秒数チップ（**そのダンサー色寄りの文字色**）／マイ・フォーカス／削除／閉じる
- **2段目**: 6色のカラーチップ（22px、選択中はピンクのリング）／フォーカス中は右端に「マイ・フォーカス中」

> 個別秒数チップの配色を変えているのは、ドックのシーン秒数チップと見分けるためです。

### 3-5. D. ドック

上から4段。

1. **ハンドル** — タップでシーン一覧シートを開く
2. **選択中シーン行** — 再生ボタン（40pxピンク円）／`S3` バッジ＋シーン名（破線枠＋鉛筆）／`⏱ 1.5 秒でここへ` チップ／右端にゴミ箱
3. **ストリップ** — コマ74px固定＋コネクタ（`→ 1.5s`）＋末尾に「＋」（52px）。横スクロールで1コマずつスナップ、コマのドラッグで並び替え
4. **ドットレール** — 区間バー＋現在地の点＋`3/5`。**見た目だけの置き換えで、中身は透明にした `<input type="range">`**（ドラッグ・矢印キー・読み上げをそのまま活かすため）

### 3-6. シート（画面下から出る）

閉じ方は3通り：下へドラッグ／背景タップ／Escape。

**シーン一覧シート**（画面の82%の高さ）
- 見出し「シーン」＋「5件 · 合計 7.4s」
- 行 = 78pxサムネイル（**格子つき**）＋番号＋名前＋`1.5s でここへ`
- **選択中の行だけ** `名前 / 複製 / 削除` の3ボタンが開く
- 縦ドラッグで並び替え
- 末尾に「いまの配置をコピーして追加」

**ダンサー追加シート**
- 名前入力（46px）
- **次に割り当てられる色**を6色の中で強調表示＋「4人めの色になります。あとからインスペクターで変更できます」
- **どこに立つか**をミニチュアで図示＋説明文
- キャンセル / 追加する（1:2）

## 4. その他の画面

### プロジェクト一覧

- ヘッダー（ブランド＋ログアウト）
- 作成フォーム：入力＋46pxの丸ボタン（Plus）
- **カード**：左に先頭シーンの隊形サムネイル84px／中央にタイトル＋`5 シーン · 6 人 · 7.4s`（Mono、尺のみピンク）＋ダンサー色ドット／右端にゴミ箱44px
- シーン0件のプロジェクトは破線サムネイル＋「タップして最初のシーンを作る」
- **0件の空状態**：破線カード＋4つのドットの隊形イラスト＋「上の入力から曲名を入れると、ステージが1つ立ち上がります。」

### ログイン／新規登録

- 背景：格子を `perspective(600px) rotateX(52deg)` で床に倒す＋上部にピンクの照明
- ブランド：5色ドットの山型（＝隊形が組まれる瞬間）＋`Choreon` 34px＋「紙のフォーメーション図を、動く絵コンテに。」
- カード：`backdrop-blur`
- 送信中：ボタン内にスピナー＋「ログイン中...」
- 登録完了：フォームごと差し替え（メールアイコン＋案内＋戻るリンク）

### 共通の状態

- **トースト**：画面下部中央。角丸12px・枠線・**種類ごとのアイコン**（成功=チェック/緑、失敗=×/赤）。4秒で自動的に消える
- **確認ダイアログ**：削除3箇所（シーン／ダンサー／プロジェクト）で共通。**巻き添えで消えるものを実数のチップで表示**。実行中は両ボタン無効

## 6. 変えてはいけないもの

- **ステージの座標系とアスペクト比** — 1マス=1ユニット=実寸約90cm。ダンサーは％配置なので、比率が崩れると全員の位置がずれる
- **上=バックステージ／下=客席側**
- **ダーク1本＋ピンクアクセント**（ライトテーマなし）、グレーは zinc
- **操作方法** — ドラッグ8px閾値／回転ハンドル／サムネイル直接ドラッグ／シーン選択の4通り／曲線の制御点ドラッグ・ダブルクリックで直線化
- **タップ領域 最低44px**
- **日本語のドメイン用語** — バックステージ／客席側／シンメトリーモード／顔被りチェック／マイ・フォーカス
- **スマホ縦持ち最優先・1カラム**

## 7. デザイン確定案からの逸脱

実装時に確定案（Turn 5）から意図的に変えた点です。

| 項目 | 確定案 | 実装 | 理由 |
| --- | --- | --- | --- |
| 表示切り替え | ステージ上に3連セグメントを常設 | **ヘッダー右端のボタン＋メニュー** | アイコンだけでは何のトグルか初見で分からず、ホバーで名前を出してもポインタの無いスマホでは解決しなかった。畳めば名前が読め、48px の行もステージに返せる |
| シンメトリーモード | ヘッダーのピル | **同じメニューの中** | 片方をメニューに畳んだ以上、モード/表示の置き場所を2つに分ける利点が、ヘッダーの横幅を1つ余計に使う不利を上回らなくなった |
| ダンサー追加の入口 | ドックの「＋」またはインスペクター横 | **ヘッダー** | プロジェクト単位の操作で、シーンを扱うドックとは層が違うため |
| 一覧の「配置」数 | 実測値 | `シーン数 × 人数` | 全プロジェクトの全配置を数えるクエリが増えるため、上限値で代用している |

## 8. 既知の課題

- **タッチでのモード名**：メニューを開けば読めるが、閉じている間はアイコンのみ。ホバーの無い環境では「押す前に分かる」がヘッダーのボタン1つに集約されている
- **インスペクターがステージの下端を覆う**：ステージが動かないことと引き換え。客席側に立つダンサーが隠れる場合がある（×で閉じられる）
- **トーストの「再試行」**：確定案にあったが未実装（失敗した操作を再実行する仕組みが必要）
