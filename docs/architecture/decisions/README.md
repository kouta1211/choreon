# 決定の記録（ADR）

## 過去の決定は README にある

フェーズ1〜6の大きな判断（競合分析・AI での作り切り・インフラの壁・
ネイティブ版を止めた判断・端末の分業）は **README「開発の記録」が正**。
あれは読み物として通して読む前提で書いてあるので、ここへ写さない。

## ここに書くのは、これから決めること

README に足すほど大きくないが、**後から「なぜこうなっているのか」を
聞かれる**判断を1件1ファイルで置く。

```
0001-<短い題>.md
```

対象になるのは、たとえば:

- ライブラリを選んだ / 捨てた
- データの持ち方を変えた（時間の持ち方を作り直したような話）
- 2つのやり方のどちらかに寄せた（同じ操作が2箇所で意味を持つ、など）

対象にならないもの: いつもの実装、規約（→ `.claude/rules/`）、
失敗の記録（→ `../../lessons_learned.md`）。

型は [_template.md](_template.md)。**「選ばなかった案」の欄を空にしない。**
そこが後から効く。
