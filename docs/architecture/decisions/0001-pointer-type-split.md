# 0001. ステージの空きドラッグは、マウスなら「囲む」・指なら「シーンを送る」

- 日付: 2026-08-18
- 状態: 採用

## 何に困っていたか

PC 特化の一歩として**囲んで選ぶ（矩形選択）**を足したかった。
ところが、その操作（ステージの何も無い所をドラッグ）は
**払ってシーンを送る**（`useStageScrubGesture`）が既に使っていた。
1つのジェスチャに2つの意味は持たせられない。

## どうすることにしたか

**どちらかをやめるのではなく、入力機器で分けた。**
`event.pointerType === "mouse"` なら囲む、それ以外（指・ペン）なら送る。

- 囲むのはマウスの作法（Finder も Figma もそう）で、**指で囲むと誤爆する**
- PC でシーンを送る道は ← → キー・下の帯のコマ・ドックに残っている
- スマホは閲覧が主で、送る操作の方が要る（→ README フェーズ6 の分業）

実装は `features/canvas/hooks/useMarqueeSelection.ts` と
`components/organisms/CanvasBoard.tsx` の `stagePointerHandlers`。

## 選ばなかった案と、その理由

- **払って送るをやめる** … スマホの閲覧・確認でいちばん使う操作。潰せない
- **修飾キーを押している間だけ囲む** … 囲むのは選択の起点で、
  毎回キーを押させるのは重い。修飾キーは「足す・外す」に取ってある
- **囲むのを別のボタンで有効にするモード** … モードは戻し忘れる

## これで何が制約になるか

- **タブレット（タッチのある作る側）では囲めない。** 分業上、作る側には
  タブレットも入っているので、ここは穴として残っている。
  外付けマウスを繋げば囲める
- **入力機器で意味が変わる操作が1つできた。** 同種の操作を足すときは、
  ここに揃えるか、揃えない理由を書くこと
